## ユーザ指示（スコープ確定時）

> 既存のものを流用しつつ、E1,2,3,4 を分けて独立に動くようにして。
> 想定している RQ: Open-Weight LLM に埋め込まれた提供者由来の潜在的な制御機構は、モデルの公開と
> Fine-Tuning を経ても保持され、オンライン環境における元モデルおよび派生モデルの外部制御を
> 可能にするか。特にトリガー型ではなく、動的な動作の制御（外部から与えられる異なる指示に応じて
> 派生エージェントの振る舞いが変化する）を今回は扱う。

## 計画書の E1〜E4

| Stage | 検証する性質 | 本実装での対応 |
|---|---|---|
| E1 | Implantation：元モデルに動的制御機構を埋め込めるか（行動＋内部機構） | `--mode pc_e1` |
| E2 | Original-Model Control：提供者署名付き命令で元モデルを外部制御できるか（排他性） | `--mode pc_e2` |
| E3 | Inheritance：FT 後も機構が継承されるか（行動継承＋内部回路継承） | `--mode pc_e3` |
| E4 | Derived-Model Control：派生モデルを外部制御できるか（横断制御＋談合＋E3対応） | `--mode pc_e4` |

## 制約

- 既存の `--mode cc`（E0〜E5 一括）経路とコミット済み `results/` は変更しない。
- GPU 実行（学習・実モデル推論・実回路分析）はユーザ承認制。dry-run の Mock で検証する。
- コメント・ドキュメント・ロール文は日本語（既存リポジトリに合わせる）。
