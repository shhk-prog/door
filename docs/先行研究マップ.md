# 先行研究マップと本研究の範囲

本書は、`docs/deep-research-report*.md`（4本のサーベイ）と計画書
（`研究実験計画書.md` / `backdoor計画書.md` / `統合研究計画書_programmable_backdoor_collusion.md`
＋改訂記録 `programmable_backdoor_revision_5points/`）を読み込み、先行研究が
**何をしているか / どんなモデル・データ・ベンチマークを使うか / どんな脅威モデルか** を整理し、
その上で **本研究がどこを埋めるか** を一枚で分かるようにするものである。

## 0. 全体像（3行）

- 先行研究は大きく **(A) バックドアの継承・持続**、**(B) エージェント固有バックドア**、
  **(C) マルチエージェント攻撃**、**(D) 談合（バックドア非依存）**、
  **(E) 可変命令／制御インターフェース系** に分かれる。
- 「同じ悪性 open-weight 祖先 → 独立に clean FT された**複数**の派生先を、提供者が配備後に
  **可変命令で横断制御**し、結果として**談合**する」経路を、祖先共有と目的共有を分離して
  因果的に検証した研究は**存在しない**。
- 本研究（Paper 1）はその空白のうち **programmability（可変命令）× FT残存 × 複数派生先への横断制御 ×
  監査可能性** を核に据え、**談合は下流帰結（RQ5 / Paper 2）** として扱う。

## E. 可変命令／制御インターフェース系（本研究に最も近い発想）

| 研究 (ID) | 何をする研究か | 脅威モデル / 要点 |
| :-- | :-- | :-- |
| **Cordyceps**（2026, Shao ら, covert control attacks） | 固定 trigger–response でなく、**自然文に任意の plaintext 命令を埋め込み LLM に decode・実行**させる semantic hiding channel | 攻撃者が操作できるのは victim の **FT データのみ**。base の重み/構造には不可アクセス |
| **Backdoor-Powered Prompt Injection**（EMNLP 2025, Chen ら） | SFT poisoning で backdoor を入れ、trigger 活性時に trigger で囲まれた **注入命令を実行**（t+c→execute(c)） | 中心は instruction hierarchy / prompt injection 防御の無効化 |
| **Programmable Backdoor in VLMs**（2026/08, "Once Poisoned, Arbitrarily Controlled"） | one-to-one/N-to-N の trigger–target でなく、poisoning 後に **学習時未見の target を推論時に指定**可。target 選択を学習から分離。"programmable backdoor" の語を明示 | target を実行時に可変指定 |
| **The 'Sure' Trap**（2025） | trigger 付き未知 unsafe prompt で harmful continuation が増える＝ compliance を on/off する **behavioral gate / latent control signal** と解釈 | 制御信号としての backdoor |
| Indirect Prompt Injection / Triggers Hijack Language Circuits (2026) / Backdoor Decontamination Dynamics (2026) | retrieved data 経由の遠隔命令 / backdoor が既存回路を乗っ取る機構解析 / trigger 認識と実行は分離可能・除去後も痕跡 | reachability と機構解析の根拠 |

## 先行研究マップ（2軸配置）

縦 = **制御の性質**（固定 trigger→固定 payload ↔ 可変命令＝制御インターフェース）、
横 = **対象範囲**（単一モデル/エージェント ↔ 供給網で独立 FT された**複数**派生先・MAS）。

```
                     単一モデル / 単一エージェント            供給網・複数独立派生先 / MAS
                ┌───────────────────────────────┬───────────────────────────────┐
  固定 trigger   │ BadPre, SynGhost, Sleeper,     │ BadAgent, BackdoorAgent,      │
  → 固定 payload │ BAD-BOOM, TransTroj, PersistBD,│ Collaborative Shadows,         │
  (Logic Bomb型) │ ASPIRER, FAB, FT-data窃取,     │ Conjunctive Prompt, AiTM,      │
                │ AgentPoison, Watch Out, DemonAg│ BCBI(閾値型・最近接)           │
                ├───────────────────────────────┼───────────────────────────────┤
  可変命令       │ Cordyceps, Backdoor-Powered    │                               │
  = 制御         │ Prompt Injection, VLM          │   ★ 本研究（空白セル）        │
  インターフェース│ Programmable Backdoor,          │   provider 可変命令で          │
                │ The 'Sure' Trap                │   複数独立派生先を横断制御     │
                └───────────────────────────────┴───────────────┬───────────────┘
                                                                 │（下流帰結）
  談合(provenance非依存): Colosseum, Emergent Collusion,         ▼
  Algorithmic/Strategic Collusion, Secret Collusion … ──→  provider-induced collusion
```

- 左下（可変命令×単一）は近年立ち上がりつつあるが、**供給網で独立 FT された複数派生先への横断制御**（右下）は空白。
- BCBI は右上に位置する **最近接の競合**だが、(i) 固定 payload 的（threshold で単一の敵対目的に切替）、(ii) 全 agent が**同じ** poisoned model を instantiate（独立 FT された別個の派生先ではない）、(iii) 発火条件は peer evidence threshold であって provider の可変命令ではない。
- 談合研究（D）は悪性 provenance を原因変数として扱わない。本研究は談合を **provider-induced（provenance 由来）** と **naturally emergent** に分離する点が新しい。

## 本研究の範囲（Paper 1 と Paper 2）

改訂後の計画（`programmable_backdoor_revision_5points/`）に基づく。

### Paper 1（本体）＝ RQ1〜RQ4 を核に
- **RQ1 Programmability:** 上流モデルは **programmable な隠れ制御 policy** を持ち得るか（固定 payload ではなく命令内容で行動が変わるか）。
  - 汎化を3段階で評価：**Level 1 暗記 < Level 2 held-out 汎化（未知 target/未知 operator）< Level 3 合成的汎化**。
- **RQ2 FT Survival:** それが独立した clean downstream FT を生き残るか（Persistence Ratio）。
- **RQ3 Cross-Descendant:** 1つの上流制御 interface が、独立 FT された**複数の派生先**に横断的に残るか（CDCR）。
- **RQ4 Auditability:** 通常の単体監査で検出・除去できるか。
- **範囲外として明確化:** 搬送路は **capability と reachability を分離**（`Embedded Capability + Reachability → Realized Control`）。到達性は Direct / Indirect Environmental / Agent-to-Agent Relay の3経路として扱い、provider が配備環境へ直接アクセスする前提は置かない。
- **認証の位置づけ:** `provenance_sig: "Cedar-…"` は暗号的認証ではなく **Secret Activation Namespace**。認証と汎化の関係は断定でなく **Authentication–Generalization Trade-off Hypothesis** として検証。

### Paper 2 / 下流拡張 ＝ RQ5
- **RQ5 Collusion:** 横断制御の帰結として、複数派生先が provider に都合よく**談合**するか。
  - **provider-induced collusion** と **naturally emergent collusion**（Colosseum / Emergent Collusion）を分離。
  - 祖先共有（shared provenance）と目的共有（shared objective）を 2×2 で切り分け、Collusion Lift / Welfare Regret で測る。

### タイトル案
`Inherited Covert Control: Programmable Backdoors Across Fine-Tuned Descendants of Open-Weight LLMs`

## 最近接研究との差分（何を新しく足すか）

| 先行研究 | 扱っていること | 本研究が追加する点 |
| :-- | :-- | :-- |
| Sleeper Agents | 条件付き policy が安全学習後も残存 | 固定条件でなく **provider が配備後に送る可変命令**。複数独立派生先への継承 |
| Malice in Agentland（最近接・供給網） | 悪性 base を clean agentic FT しても単一 agent に backdoor 残存 | 単一→**複数独立 descendant**、固定→**programmable**、供給網→**横断制御・談合** |
| BCBI（最近接・MAS） | 協働 evidence の threshold で発火（同一 poisoned model を配置） | 発火条件でなく **可変命令の制御 interface**。同一 model ではなく**独立 FT された別派生先**間の不変性 |
| BackdoorAgent | workflow stage 間の trigger 伝播 | 単一 agent 内でなく **上流重み由来の制御 interface の継承** |
| Colosseum / Emergent Collusion | provenance 非依存の談合評価・因果介入 | 談合の原因として **モデル供給源（provenance）** を操作し、provider-induced と分離 |
| Cordyceps / Programmable Backdoor in VLMs | 可変命令・target 分離（単一モデル） | **供給網で独立 FT された複数派生先への横断制御**と、その FT 残存・監査 |
